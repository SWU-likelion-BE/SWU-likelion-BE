# 첨부 명세 적용 기준

## 사용한 자료

- API 명세서: 엔드포인트·HTTP 메서드·담당자·공통 응답.
- 전임자/후임자 기능명세서 v.3: 역할별 동작과 수치·예외 규칙.
- 백엔드 가이딩 자료 정리: ERD, 계층 역할, 트랜잭션·AI 작업·문서 버전 관리.
- 역할 분담: 퀴즈·학습 진행·완료 판정 담당. Q&A·체크리스트 담당은 API 명세의 최유정 배정을 적용.

| 최소 완성도 80% 이상, 퀴즈 커트라인 70점 이상 | 적용. 입력 미설정 시 허용 최솟값 사용 |
| 후임자 질문 등록·수정, 전임자 답변 | 적용. 실제 공개 문서 검증 어댑터 연결은 대기 |
| 답변 등록 시 질문 해결 상태 전환 | 적용 |

| 질문·답변 등록 알림, 중복 방지 | 이벤트 저장 적용. 알림 발송 모듈 연결은 대기 |
| 전임자·후임자 본인 확인 저장 | 적용. 사용자·역할 권한 검증 및 중복 방지 |

| 최소 1회 질문 | 활성 후임자마다 요청·승인에서 검사 |
| 모든 페이지 열람 | 활성 후임자별 검사. 실제 페이지 열람 어댑터 연결 필요, 숙지 확인과 구분 |

## 문서에 없는 규칙은 강제하지 않음

- 통과 후 재응시 금지는 제거했다. 재시험 대기는 명시된 미통과 경우에만 적용한다.
- 질문 수정 시 미해결 상태로 강제 전환하는 규칙은 제거했다. 기존 해결 상태와 답변 원문을 유지한다.
- 기준 변경 시 본인 확인을 무효화하고 재확인을 요구하는 규칙은 제거했다.

동시 수정 방지를 위한 revision, 페이지 크기, 입력 길이 제한, 요청·응답 DTO는 구현 세부사항이다.
변경된 기준으로 이미 저장된 퀴즈 결과를 다시 쓰지 않으며, 새 응시에 현재 기준을 저장한다.
이는 결과 이력을 보존하는 현재 구현 방식으로, 문서가 별도 적용 시점 정책을 정한 것은 아니다.

## 문서 간 충돌 처리

- API 경로: 가이드의 `/api/v1`은 제안이므로 API 명세가 명시한 `/api` 적용.
- 오류 필드: 가이드의 `fieldErrors/traceId` 제안 대신 API 명세의 `errors` 적용.
- 완료 흐름: 기능명세의 자동 완료 설명과 달리, API에는 전임자 완료 처리·양측 본인 확인·관리자 최종 승인 엔드포인트가 각각 있다.
  백엔드 가이드도 관리자 승인 시 조건 재검증을 요구하므로, 명시적인 완료 요청·확인·승인 구조를 구현했다.

완성도 산식이나 미연동 문서의 공개 여부를 임의로 가정하지 않는다. 완료 조회는 기준·확인·요건별 미충족 사유와 승인 상태를 제공한다.
문서 어댑터 또는 계산에 필요한 데이터가 없으면 점수 null과 `eligibilityEvaluated=false`를 반환한다. 다중 후임자의 프로젝트 집계와 체크리스트 0건 처리도 미정으로 보류한다. 양측 확인만으로 프로젝트를 완료하거나 승인하지 않는다.

## 남은 개발·연동

- 퀴즈 생성 요청·작업 저장·확보·결과 검증은 구현했다. 실제 AI 워커와 공개 문서·근거 섹션 연결이 남았다.
- Q&A 공개 문서 검증과 실제 알림 발송.
- 체크리스트 완료 API는 구현했다. 공개 문서 항목 검증 어댑터 연결이 남았다.
- 필수 조건 평가·완료 요청·관리자 승인·감사 기록과 개인별 각 25% 계산을 구현했다. 실제 문서·업무·인터뷰·숙지·열람 데이터 연동과 다중 후임자 프로젝트 집계·빈 체크리스트 정책이 남았다.
- PostgreSQL 17 검증. EC2·nginx·CI/CD 배포는 최유정 담당 범위가 아니다.

## 검증

2026-11-27 후속 정책 반영: 개인별 각 25% 계산과 후임자별 최소 질문 고정 후 전체 124개 테스트 통과(실패·오류·건너뜀 0).

2026-11-27: 최소 질문·전체 페이지 열람 조건 추가 후 PostgreSQL 15에서 전체 113개 테스트 통과(실패·오류·건너뜀 0).
질문 0건 차단, 질문 후 답변 필요, 숙지와 열람 구분, 승인 시 열람 재검증, 열람 어댑터 부재 차단, 후임자별 질문 설정을 검증했다. 실제 페이지 열람 데이터는 테스트 대역을 사용했다.

2026-11-25: 추가 구현 후 격리된 PostgreSQL 15에서 V1~V9와 JPA 스키마 검증 및 전체 테스트 통과를 확인했다.
문서·AI·알림 담당 모듈과 연결된 전체 사용자 흐름이나 PostgreSQL 17 배포 검증을 완료한 것은 아니다.

구체적인 어댑터와 AI 작업 처리 계약은 [학습·완료 연동 계약](learning-integration.md)을 참고한다.
